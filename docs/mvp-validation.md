# MVP 검증 체크리스트

## 환경
- 실내(형광등), 실외(주간), 역광, 저조도
- 단일 인물, 2인 프레임
- 중급 안드로이드 기기 1대 이상

## 성능 기준
- 실시간 피드백 체감 지연 300ms 내
- 프리뷰 체감 FPS 20 이상
- 10분 연속 사용 시 발열/프레임 저하 관찰 기록

## 기능 검증
- 카메라 수평을 의도적으로 기울였을 때 보정 안내 문구 출력
- 피사체 좌우/상하 이동 시 프레이밍 피드백 변화
- 어깨 비대칭/상체 기울기 상황에서 자세 문구 출력
- 점수 UI가 급격히 깜빡이지 않고 부드럽게 변하는지 확인

## 사용자 검증
- 최소 5명 대상 사용성 확인
- 질문: "가이드가 촬영 구도/자세 개선에 도움이 되었는가?"
- 목표: 긍정 응답 80% 이상
